# Segurança

## Relato de vulnerabilidades

Não abra uma issue pública com detalhes exploráveis. Use o recurso **Report a vulnerability** na aba Security do repositório para enviar um relato privado.

Inclua a área afetada, impacto, passos mínimos de reprodução e qualquer mitigação conhecida. Não acesse dados de terceiros e não execute testes destrutivos no ambiente publicado.

## Escopo

Este repositório contém apenas o frontend. Problemas na API devem ser relatados no repositório [fastapi-merchant-app](https://github.com/vsys-val/fastapi-merchant-app).

Dependências são verificadas com `npm audit`, e toda alteração deve passar pelos testes e pelo build automatizado.
